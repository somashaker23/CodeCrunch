# Intuition
Think to keep track of the frequency of each number in the array. Then, find the top k frequent numbers by iterating through the frequency map.
Don't sort the frequency map, just find the top k frequent numbers by iterating through the map and keeping track of the top k numbers.

public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> frequencyMap = new HashMap<>();
    for (int num : nums) {
        Integer aDefault = frequencyMap.getOrDefault(num, 0);
        frequencyMap.put(num, aDefault + 1);
    }
    Set<Map.Entry<Integer, Integer>> entries = frequencyMap.entrySet();
    int[] result = new int[k];
    for (int i = 0; i < k; i++) {
        for (Map.Entry<Integer, Integer> entry : entries) {
            if (result[i] < entry.getValue()) {
                result[i] = entry.getKey();
            }
        }
        int finalI = i;
        entries.removeIf(entry -> entry.getKey() == result[finalI]);
    }
    return result;
}
