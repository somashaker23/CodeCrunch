# Intuition
Think each each anagram belong to a family, and each family has a unique id, which is the sorted string of the anagram.
# Approach
<!-- Describe your approach to solving the problem. -->
A family map can be used to group anagrams together. For each string, sort the characters to create a unique identifier for the family. Use this identifier as a key in the map, and add the original string to the list of that key.
# Complexity
- Time complexity: $$O(n^2)$$
<!-- Add your time complexity here, e.g. $$O(Nklogk)$$ -->

- Space complexity: $$O(1)$$
<!-- Add your space complexity here, e.g. $$O(n)$$ -->

# Code
```java
public List<List<String>> groupAnagrams(String[] strs) {
    HashMap<String, List<String>> anaGramFamily = new HashMap<>();
    for (String current : strs) {
        char[] charArray = current.toCharArray();
        Arrays.sort(charArray);
        String familyId = new String(charArray);
        if (anaGramFamily.containsKey(familyId)) {
            anaGramFamily.get(familyId).add(current);
        } else {
            ArrayList<String> value = new ArrayList<>();
            value.add(current);
            anaGramFamily.put(familyId, value);
        }
    }
    return new ArrayList<>(anaGramFamily.values());
}
```
