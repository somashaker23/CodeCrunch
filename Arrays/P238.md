# Intuition
Think like we are sweeping product from left to right and then from right to left.
every sweep, we are storing the product of all elements to the left and right of the current element in the result array.

```java
  public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    int leftProduct = 1;
    for (int i = 0; i < n; i++) {
        result[i] = leftProduct;
        leftProduct *= nums[i];
    }

    int rightProduct = 1;
    for (int i = n - 1; i >= 0; i--) {
        result[i] = result[i] * rightProduct;
        rightProduct = rightProduct * nums[i];
    }

    return result;
}
```
