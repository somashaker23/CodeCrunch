# Intuition

Anagram means length shoudl be same and all characters should be same in both strings.

# Approach

check if length of both strings are same, if not retun false.
Then convert both strings to character arrays and sort them.
Finally, check if both sorted arrays are equal.

# Code

```java 
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }

        char[] s_chars = s.toCharArray();
        char[] t_chars = t.toCharArray();

        Arrays.sort(s_chars);
        Arrays.sort(t_chars);

        return Arrays.equals(s_chars, t_chars);
    }
}
```
